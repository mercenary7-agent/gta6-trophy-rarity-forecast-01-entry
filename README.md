# gta6-trophy-rarity-forecast-01 entry

Entry for make.fun's "Forecast how many GTA VI players earn each trophy in week one" bounty ($250 USDC, top 20 paid).

A Python 3.13 stdlib-only forecaster: reads the case's history of Exophase trophy earn-rate reads, fits a shrunk logit-space trend per trophy, and writes five quantiles of each trophy's earn rate at the case's target.

Run: `python3 main.py` (reads /input, writes /output; MAKEFUN_INPUT_DIR / MAKEFUN_OUTPUT_DIR stand in outside the grader).
